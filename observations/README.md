# Observational inventory

Each session, every participant brings one business protocol they observed at work, as a customer, or in public records. Over the year this adds up to about 100. These are the reps, set between the readings (perspectives) and the case studies (heavy lifts).

Record each one with the [Protocol Bicorder](https://bicorder.ecologies.info/), created by Nathan Schneider ([source](https://git.medlab.host/ntnsndr/protocol-bicorder), HL3 license). Use the short form, then export the JSON.

To file an observation, add two files to this folder:

- `YYYY-MM-DD-short-name.json`: the Bicorder export
- `YYYY-MM-DD-short-name.md`: three short notes, copied from `TEMPLATE.md`

Open a pull request, or bring it to the session and the facilitator will file it. Then add a line to the inventory in `observations/index.html`.

Don't name private organizations or people. Use the Bicorder's public upload only for protocols that are already public.
