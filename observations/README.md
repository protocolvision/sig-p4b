# Observational inventory

Each session, every participant brings one business protocol they observed at work, as a customer, or in public records. Over the year this adds up to an inventory of roughly 100 protocols. These are the reps, set between the readings (perspectives) and the case studies (heavy lifts).

To add one, copy `TEMPLATE.md` to `YYYY-MM-DD-short-name.md` in this folder and open a pull request. You can also bring it to the session, and the facilitator will log it. Then add a line to the inventory list in `observations/index.html`.

Don't name private organizations or people.
