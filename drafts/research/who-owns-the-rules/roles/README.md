# Role library

Representative job descriptions, capability models and coded activities for roles that are already
emerging around AI agents, plus five analogue roles from industries that already regulate rule work for
automated systems. Built 10 October 2026 from search-engine summaries only (grade S): no page could be
opened. The end-to-end rerun (`../RERUN.md`) downloads every source and brings each role to 6–10 full
postings and official capability models.

Each file has: status, representative job descriptions (with verbatim excerpts only where seen), capability
models, activities with a preliminary code (PV finding rules, PE designing rules, RD deciding rule changes,
AO agent operations, OT other; marked "collector's code") and sources. Source lists for downloading:
`sources-ops.csv`, `sources-builders.csv`, `sources-governance.csv` (all feed `../corpus/manifest.csv`).

**Pattern so far (to verify in the rerun):** rule design (PE) appears inside most emergent roles; deciding
rule changes across functions (RD) is thin everywhere, and no posting clearly gives it to the holder; the
analogue roles show certification and named accountability that the emergent roles lack.
